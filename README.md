# About

Basic math game with random questions and a score system.
The data persists locally in a List while the programs runs. Once the program closes, all data is erased. 

# How to execute it

**1.** Clone the repo

**2.** In the root of the project, execute the next command in the terminal:

```
    dotnet run
```
